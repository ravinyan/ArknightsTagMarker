# ArknightsTagMarker

Up to date with https://www.reddit.com/r/arknights/comments/1m1xsrj/recruitment_tag_quick_reference_guide/
, will update the application if i see somewhere that there is newer up to date version of this (so basically only when someone will tell me about it).

Application that shows all 4* and 5* tag results from recruitment. There are 2 versions for PC Client and for LDPlayer, for other emulators try changing process name in ProcessName.txt file and app should still work correctly... probably?

Latest release [here](https://github.com/ravinyan/ArknightsTagMarker/releases) + some info on how game window should be set up for the OCR to have the best accuracy.
